# @copit/cli

[copit](https://github.com/huynguyengl99/copit) for Node projects: copy reusable source code
from GitHub repos, HTTP URLs, and ZIP archives into your project.

```bash
npx @copit/cli add <source>     # run once
npm install -g @copit/cli       # then: copit add <source>
```

npm installs only the prebuilt binary for your platform. Docs: <https://github.com/huynguyengl99/copit>.
